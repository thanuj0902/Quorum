Process

How Quorum's Multi-Agent Verification Works

Each verification runs through four specialized AI agents in sequence. Every agent works independently, ensuring no single point of failure in the fact-checking process.

🔍

Research Agent

Extracts factual claims from your input and gathers sources with initial confidence scores.

🛡️

Verification Agent

Independently cross-references each claim against reliable sources and adjusts confidence.

⚠️

Hallucination Detector

Finds contradictions and flags potential hallucinations or fabricated data.

📄

Synthesis Agent

Compiles a citation-backed report with per-claim confidence scores and executive summary.

FAQ

Frequently Asked Questions

What is Quorum AI fact-checking?

Quorum is a free multi-agent AI fact-verification system that uses four independent AI agents to research claims, cross-verify facts, detect hallucinations, and compile citation-backed reports with per-claim confidence scores.

How does multi-agent verification work?

Each claim goes through four specialized AI agents in sequence: a Research Agent gathers sources, a Verification Agent cross-checks facts, a Hallucination Detector flags fabricated data, and a Synthesis Agent compiles the final report.

Is Quorum free to use?

Yes, Quorum is completely free to use. It offers a demo mode that works without an API key, and a live mode that uses your own Anthropic API key for real AI-powered verification.

Can I share fact-check reports?

Yes, Quorum generates unique shareable links for every completed report. You can share these links with anyone and they can view the full report without needing an account.
